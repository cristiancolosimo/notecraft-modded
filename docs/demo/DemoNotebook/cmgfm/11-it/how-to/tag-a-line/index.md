Un'etichetta segna una riga come qualcosa: una cosa da fare, qualcosa di importante, una domanda
a cui rispondere. Clicca in una riga, poi su **Home** e sulla casella Etichette. Chiedere di
nuovo la stessa etichetta la toglie.

## Da fare

- [ ] Apri questo quaderno
- [x] Leggi la pagina di benvenuto
- [ ] Spunta la casella qui sopra cliccandola

Una riga da fare è una voce di elenco di attività, che ogni lettore Markdown capisce.

## Le altre etichette

#important Partire venerdì, non sabato.

#question Il treno ferma all'aeroporto?

#idea Tenere i biglietti nella pagina, non nella posta.

#remember Il codice di prenotazione è nel file allegato.

NoteCraft disegna il segno al posto della parola, ma nel file c'è la parola, quindi le tue note
restano leggibili in qualsiasi editor e ricercabili da terminale. Una parola che somiglia solo a
un'etichetta, come #ideas senza spazio dopo, viene lasciata stare.

## Cosa non c'è ancora

Le etichette personalizzate e una pagina di riepilogo che raccolga ogni riga etichettata non sono
ancora state realizzate. Il pulsante Trova etichette lo dice.
