Questa pagina è un file **HTML**. Le altre pagine di questa sezione sono file **Markdown**. Si modificano allo stesso modo e sulla pagina non si distinguono; il formato compare in alto a destra, accanto all'indicazione che la pagina è salvata.

| Formato | File | Adatto a |
| --- | --- | --- |
| HTML, l'impostazione predefinita | index.html | Impaginazione ricca e pagine arrivate da altrove |
| CommonMark + GFM | index.md | Differenze e unioni pulite, e lettura del file da solo |

## Dove si sceglie

1. Il formato scelto quando crei la pagina.
2. Il formato più vicino impostato su una sezione, un gruppo o un quaderno sopra di lei.
3. L'impostazione globale, la casella **Formato predefinito** nella barra in alto.
4. L'impostazione predefinita integrata, HTML.

Un'impostazione cambia solo le pagine nuove. Quelle che hai già mantengono il loro formato, visibile dal nome del file, quindi non serve alcuna impostazione per leggere una pagina.

## Guarda il sorgente di questa pagina

Clicca il pulsante `< >` accanto alla pagina. L'intestazione del file riporta l'identità e le date della pagina come tag `<meta name="notecraft:...">`; una pagina Markdown le riporta nel front matter. NoteCraft modifica solo ciò che sta dentro `<body>`.
