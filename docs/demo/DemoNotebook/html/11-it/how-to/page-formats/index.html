Dove si sceglie

  1. Il formato scelto quando crei la pagina.
  2. Il formato più vicino impostato su una sezione, un gruppo o un quaderno sopra di lei.
  3. L'impostazione globale, la casella Formato predefinito nella barra in alto.
  4. L'impostazione predefinita integrata, HTML.

Un'impostazione cambia solo le pagine nuove. Quelle che hai già mantengono il loro formato, visibile dal nome del file, quindi non serve alcuna impostazione per leggere una pagina.
